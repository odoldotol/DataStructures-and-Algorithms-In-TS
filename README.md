# DataStructures-and-Algorithms-In-TS

JS 는 유연하고 다재다능함을 지향하면서 다양한 패러다임을 위한 복잡성은 증가하는데 비교적 내장 자료구조나 알고리즘은 단순함.
Leet 코드 기반 학습을 진행하면서 최소한의 유용성을 갖춘 TS 코드셋을 만들어 보려고 함.
그 과정에서 자료구조/알고리즘 의 기본적인 이해를 넘어서 JS 에서의 활용을 고민해보자.

### 사용성
- 실용적이어야 함(성능, 기능, 확장성)
- 범용성을 과하게 해치지 않을 정도의 구체성만 가져야함

### 엄격성
- 의도하지 않은 실행을 막고 적절한 에러를 던져야함
